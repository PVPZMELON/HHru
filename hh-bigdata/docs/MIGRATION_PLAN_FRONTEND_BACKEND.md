# План перехода со Streamlit на Frontend / Backend

## Принцип

Не переписывать рабочую систему целиком. Существующий Streamlit остаётся контрольным интерфейсом до достижения функционального паритета. Backend должен повторно использовать существующие ETL, DB и analytics модули.

## Этапы и критерии завершения

| Этап | Изменения | Проверка | Условие перехода |
|---|---|---|---|
| 0. Контракты | API_SPECIFICATION.md и FRONTEND_BACKEND_ARCHITECTURE.md | Проверка схем и параметров | Контракт согласован |
| 1. Backend skeleton | FastAPI app, settings, health endpoint | HTTP 200 и тест | Backend запускается отдельно |
| 2. Read-only analytics | filters/options и overview | Сравнить JSON с Streamlit для одинаковых фильтров | Числа совпадают |
| 3. Каталог | поиск, фильтры, сортировка, пагинация | тесты пустого результата и границ пагинации | Результаты совпадают с текущим SQL |
| 4. Аналитические страницы | salaries, skills, geography, forecast | тесты методик и малых групп | Формулы не переписаны и не изменены |
| 5. ETL monitoring | runs list/detail | сравнить с таблицей etl_runs | История отражает БД |
| 6. Сбор данных | защищённый POST и фоновые задачи | тест на малом лимите и ошибки API | Нет долгого блокирующего HTTP |
| 7. Frontend shell | React/Vite, layout, маршруты, дизайн-токены | адаптивная проверка | Все маршруты доступны |
| 8. Подключение UI | по одной странице через API | сравнение с Streamlit | Функциональный паритет |
| 9. Deployment | отдельное размещение frontend/backend | smoke + integration tests | Секреты только backend, health checks доступны |

## Первые технические шаги

1. Создать `backend/app/main.py` с FastAPI.
2. Добавить `GET /api/v1/health`.
3. Добавить тест с TestClient.
4. Добавить `GET /api/v1/filters/options`, используя `cached_options`/аналитические функции после проверки зависимости от Streamlit.
5. Не импортировать Streamlit в backend-модули.
6. Отделить функции конфигурации и аналитики от UI только там, где фактически есть Streamlit-зависимость.
7. Добавить frontend после того, как health и read-only API проходят тесты.

## Риски

- Некоторые общие модули могут импортировать Streamlit или читать st.session_state. Перед импортом в FastAPI их нужно проверить.
- Кэш Streamlit нельзя напрямую переносить в FastAPI; нужен отдельный серверный cache policy.
- Долгий API-сбор должен быть вынесен в worker.
- Временные зоны и сериализация Pandas/NumPy типов требуют явного преобразования.
- Нельзя допускать двух разных реализаций расчёта одних и тех же метрик.

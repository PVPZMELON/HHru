# Критерии приёмки: фактический статус

Статусы: **Выполнено** — реализовано и проверено; **Частично выполнено** — реализовано, но часть проверки невозможна в среде
разработки; **Не выполнено** — не сделано. Подтверждения относятся к реально выполненным проверкам.

| Критерий | Статус | Подтверждение / причина |
|---|---|---|
| Понятная структура и документация | Выполнено | `src/` по слоям, `README.md`, `docs/` (метрики, архитектура Big Data, защита) |
| Конфигурация отделена от кода | Выполнено | `src/config.py` (Pydantic) + `.env` / `.env.example`, секреты вне кода |
| Можно создать БД и таблицы | Выполнено | миграции применены к реальному PostgreSQL 16; повторный запуск раннера — 0 миграций. Docker Compose не запускался (нет демона) |
| Рабочий сценарий получения данных или импорта | Частично выполнено | импорт JSONL/JSON/CSV и демо-набор выполнены на реальной БД; клиент API hh.ru проверен только на имитированных ответах — `api.hh.ru` недоступен из среды |

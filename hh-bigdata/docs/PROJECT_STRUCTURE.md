# Структура проекта: переходный этап

Текущая и целевая структуры разделены, чтобы не ломать действующий Streamlit dashboard.

```text
hh-bigdata/
├── backend/                 # новый FastAPI backend (пока health/readiness)
│   └── app/
├── frontend/                # новый React + TypeScript + Vite UI-каркас
│   ├── src/
│   └── public/
├── src/                     # действующая логика приложения
│   ├── collectors/          # API hh.ru и импорт файлов
│   ├── etl/                 # нормализация и контроль качества
│   ├── db/                  # SQLAlchemy, миграции, загрузка
│   ├── analytics/           # SQL-запросы и метрики
│   └── dashboard/           # действующий Streamlit интерфейс
├── migrations/              # SQL миграции текущей БД
├── tests/                   # тесты ETL, БД, аналитики и API
├── docs/                    # проектная документация
├── data/                    # локальные данные; raw и секреты не коммитить
└── requirements.txt         # Python зависимости
```

## Правила переходного периода

1. Не удалять и не переименовывать `src/dashboard` до завершения переноса страниц.
2. Backend не импортирует UI-модули Streamlit.
3. Frontend не подключается к БД напрямую.
4. Существующие `src/analytics`, `src/etl`, `src/db` являются источником бизнес-логики до отдельного рефакторинга.
5. Новые endpoints покрываются тестами; для аналитических endpoints проверяется совпадение с действующим Streamlit.
6. Секреты доступны только серверу и не имеют префикса `VITE_`.

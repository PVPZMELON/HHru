# Аналитические показатели: формулы, единицы, правила фильтрации

Реализация — `src/analytics/metrics.py` (расчёт) и `src/analytics/queries.py` (выборка из БД).
Выборка для всех показателей = вакансии, прошедшие **глобальные фильтры** (дата публикации, регион,
профессиональное направление, тип данных). Вакансия с NULL в фильтруемом поле при активном фильтре по
этому полю в выборку не входит.

## 1. Правила зарплат (главное)

| Правило | Обоснование |
|---|---|
| **Сопоставимая зарплата** — только вакансии с обеими границами (`salary_kind = 'range'`); значение `salary_mid = (от + до) / 2`. | Односторонние «от X»/«до Y» — не точная зарплата; усреднять их с вилками нельзя. |
| Сравниваются только вакансии **одной валюты** и **одного признака gross/net** (`SalaryBasis`). Валюты не конвертируются. | Курсы не входят в данные; выдуманные курсы исказили бы результат. |
| Вакансии с неизвестным gross/net (`NULL`) в сопоставимую выборку **не входят**. | Нельзя утверждать, что их зарплата сравнима с gross или с net. |
| Некорректные значения (`from > to`, ≤ 0, не число, нет валюты, нереалистично большие, периодичность не «месяц») → `salary_kind = 'invalid'`, границы в вакансии **не сохраняются**, исходное значение — в `data_quality_issues`. | Исключаются из расчётов, но информация не теряется. |
| Периодичность: источник отдаёт месячную зарплату; любая другая периодичность → `invalid`, пересчёта нет. | Нельзя пересчитывать без достоверного периода. |
| Группа (регион, роль, опыт, навык) считается сравнимой, если в ней **не менее `min_n`** зарплат (по умолчанию 5, настраивается 3–30). | Медиана по 1–2 наблюдениям — шум. |
| Необязательное исключение выбросов: правило Тьюки, значения вне `[Q1 − 3·IQR; Q3 + 3·IQR]` (по умолчанию выключено; при < 8 наблюдений не применяется). | Консервативное («далёкие» выбросы), включается явно. |

**Ограничения выборки.** Зарплату указывает лишь часть вакансий, и вилка «от–до» — ещё меньшая; работодатели,
раскрывающие зарплату, могут отличаться от остальных (смещение отбора). Поэтому показатели описывают
**вакансии с вилкой в выбранной основе**, а не весь рынок.

## 2. Показатели

| № | Показатель | Формула | Единица | Фильтрация / примечание |
|---|---|---|---|---|
| 1 | Вакансии | `count(*)` | шт. | выборка |
| 2 | С указанной зарплатой | `count(salary_kind ≠ 'none')` | шт. | включает вилку, «от», «до» и `invalid` |
| 3 | Доля с зарплатой | `(2) / (1)` | % | |
| 4 | Сопоставимых зарплат | `count(range ∧ валюта ∧ gross/net)` | шт. | основа выбирается в боковой панели |
| 5 | Медиана / среднее зарплаты | `median / mean(salary_mid)` | валюта выборки / мес. | только сопоставимая выборка (4); основной показатель — медиана |
| 6 | Квартили Q1, Q3 | 25-й и 75-й процентили `salary_mid` | валюта / мес. | линейная интерполяция (Pandas) |
| 7 | Работодатели | `nunique(employer_id)` | шт. | пропуски не считаются |
| 8 | Востребованность навыка | число вакансий с навыком; доля = `/ (1)` | шт., % | навык считается один раз на вакансию; источник навыков: `key_skills` (надёжнее) и/или словарный поиск в описании |
| 9 | Распределения по региону / опыту / занятости | `count` по значению поля; пропуск = «Не указано» | шт., % | опыт — в естественном порядке |
| 10 | Динамика публикаций | число вакансий по дню/неделе `published_at`; пустые периоды = 0 | шт. | неделя начинается с понедельника; вакансии без даты не учитываются |
| 11 | Зарплата «с навыком / без навыка» | медиана `salary_mid` для вакансий с навыком и без; `diff = median_with − median_without` | валюта | показывается, только если **обе** группы ≥ `min_n` |
| 12 | Интервал разности медиан | бутстреп (1000 повторов, seed = 0), 2,5–97,5-й процентили разности медиан | валюта | воспроизводим; описывает неопределённость выборки |
| 13 | Сравнение направлений / регионов / опыта | `group_summary`: вакансии, доля с зарплатой, n, медиана, среднее, Q1, Q3 | | группы < `min_n` помечены «мало данных», медиана скрыта |
| 14 | Пропуски и некорректные данные | `share(NULL)` по полям; доли `salary_kind = 'none'` / `'invalid'` | % | в выборке (панель «Обзор») и во всей таблице (страница «Качество данных») |
| 15 | Связь навыков | коэффициент Жаккара `J(A,B) = |A∩B| / |A∪B|` по вакансиям, для топ-K навыков | 0…1 | диагональ = 1; совместная встречаемость, а не причинность |

## 3. Как формулировать выводы

Допустимо: «в выборке вакансии с навыком X имеют большую медианную зарплату (n = …)», «наблюдаемая
ассоциация», «различие в выборках». Недопустимо: «навык X повышает зарплату». На зарплату одновременно
влияют опыт, регион, роль, компания; показанная разность этого не учитывает.

## Дополнительные показатели (страницы «Что выучить» и «Прогноз»)

- **Покрытие вакансии** = число навыков вакансии, которыми владеет пользователь / число навыков вакансии. Учитываются вакансии с ≥2 навыками; «подходит» — покрытие ≥ порога (по умолчанию 60%).
- **Выигрыш навыка** = число неподходящих вакансий, которые пройдут порог при добавлении только этого навыка.
- **Тренд навыка** = доля вакансий с навыком за последние 14 дней − доля за предыдущие 14 дней (п.п.); считается при ≥30 вакансий в каждом периоде и ≥5 с навыком.
- **Прогноз публикаций**: МНК с индикаторами дня недели (+ линейный тренд, если он снижает MAE на отложенных последних 7 днях); сравнение с наивным прогнозом «как неделю назад»; интервал ≈ ±1,96σ остатков, не ниже 0. Это приближение; последний неполный день отбрасывается.

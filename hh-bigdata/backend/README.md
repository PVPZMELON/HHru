# Backend API (первый этап)

Это начальный FastAPI-сервис. Он не заменяет Streamlit и пока не содержит бизнес-эндпоинтов аналитики.
Существующие модули ETL, БД и аналитики остаются в `src/` и будут подключаться постепенно.

## Локальный запуск

Из каталога `hh-bigdata/`:

```bash
pip install -r requirements.txt
uvicorn backend.app.main:app --reload --host 127.0.0.1 --port 8000
```

Проверки:
- `GET http://127.0.0.1:8000/api/v1/health` — доступность процесса;
- `GET http://127.0.0.1:8000/api/v1/ready` — доступность настроенной БД;
- `GET http://127.0.0.1:8000/api/docs` — интерактивная OpenAPI-документация.

Для локального frontend разрешите точный origin, например:

```bash
FRONTEND_ORIGINS=http://localhost:5173
```

Секреты БД и hh.ru задаются теми же серверными переменными окружения, что и для существующего проекта. Не передавайте их из браузера.

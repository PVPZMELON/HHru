# Публикация на Streamlit Community Cloud (SQLite, без внешней БД)

Проект по умолчанию использует SQLite: база — один файл `data/hh_market.sqlite`, лежащий в репозитории. Сервер БД не нужен.
В архиве уже есть такой файл с **синтетическим** демо-набором (он помечен как синтетический в интерфейсе).

1. **Зависимости.** Streamlit Cloud ищет `requirements.txt` в **корне репозитория**. Если проект лежит в подпапке `hh-bigdata/`,
   положите содержимое `requirements-cloud.txt` в `requirements.txt` в корне репозитория.
2. **База.** Закоммитьте `data/hh_market.sqlite` (`.gitignore` его разрешает). Если файла нет, приложение само создаст схему и
   предложит загрузить синтетический набор кнопкой.
3. **Main file path:** `hh-bigdata/src/dashboard/app.py` (или `src/dashboard/app.py`, если проект в корне репозитория).
4. **Secrets не нужны.** Переменные окружения (если захотите PostgreSQL) задаются в App → Settings → Secrets: `DB_BACKEND = "postgres"`,
   `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`, `DB_SSLMODE = "require"`.

## Ограничения
* Файловая система Streamlit Cloud временная: данные, записанные приложением (кнопка демо-набора, ETL), пропадают при перезапуске.
  Постоянные данные нужно коммитить в репозиторий (собрать у себя `python -m src.pipeline …` и закоммитить новый `.sqlite`).
* SQLite рассчитан на одного пишущего процесса. Для многопользовательской записи используйте PostgreSQL.
* Если установка пакетов падает на Python 3.14, выберите Python 3.12 или 3.13 в Advanced settings.
